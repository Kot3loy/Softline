## Безопасность

| Пункт | Статус | Комментарий |
|---|---|---|
| `GIGACHAT_VERIFY_SSL_CERTS=false` | ⚠️ Осознанный компромисс | У GigaChat самоподписанный сертификат, при включённой проверке (true) API работать не будет. Формулировка «security fix» в прошлых версиях аудита — ошибка: отключение проверки — это не фикс, а снижение защиты. Корректное усиление — подключить CA-бандл GigaChat или pin сертификата; для демо не требуется. |
| `.env` в git | ✅ Не в репо, не в истории | проверено `git log --full-history` |
| `database/bot.db` в git | ✅ Не в репо | `database/` в .gitignore |
| Секреты в render.yaml | ✅ `sync: false` — вводятся вручную в дашборде | |
| Prompt injection | ✅ `_sanitize_input` в ai_engine | чистит пользовательский текст перед отправкой в модель |
| ПДн | ✅ Не собираем | только id/имя от Telegram |
