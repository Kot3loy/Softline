# Прожарка.AI — дизайн-спецификация презентации (v3)

Аудитория: комиссия SK Kids Challenge (кейс «Софтлайн Решения»).
Цель: показать, что проект соответствует этапам 1–3 + этап 4 Lead, и дать всё проверить руками.
Нарратив: **проблема → решение → доказательство → итог**. 11 слайдов.

## Дизайн-система
- Формат 16:9, 13.33×7.5″ (LAYOUT_WIDE). Поля: 0.6″.
- Фон: белый; титульный и финальный слайд — тёмный салатикового «на Honeydukes»-палитра скринов чата.
- Палитра: тёмный `#0E2A47` (текст/тёмный фон), акцент `#00A896` (teal), подложка карточек `#F6F8FA`, tint-акцент `#E3F3F1`, приглушённый текст `#5B7286`.
- Шрифт: Calibri. Кегли: заголовок слайда 28–30 bold; заголовок титула 44; подзаголовок 15–17; текст 12–12.5; подпись 11.
- Мотив: скруглённые карточки + круглые бейджи (teal-круг, белый номер/галочка). Один и тот же бейдж, карточка и кикер на каждом слайде.
- Кикер: caps, 11pt, letter-spacing, caption-цвет — над заголовком, раздельно (y 0.42 / 0.88) — не сливаются.
- Тени: только on-card, мягкие (offset 2px, blur 7, opacity 0.14). Никаких полос и подчёркиваний.

## Слайды

### 1. Титул (тёмный)
- Кикер: `SK KIDS CHALLENGE · КЕЙС «СОФТЛАЙН РЕШЕНИЯ»`
- H1: «Прожарка.AI» (44 bold, белый) + подстрока «тренажёр для абитуриента и стажёра» (26, teal)
- Лид: 2 строки, что делает бот (15, ICE, ширина 9.4″)
- 3 карточки (CARD_DK): «Демо-живой бот / @prozharka_softline_robot», «Автор / Белиевский Давид Сергеевич», «Открытый код / github.com/Kot3loy/Softline»
- Футер: «Этапы 1–3 + этап 4 уровня Lead: адаптивность, аналитика, PDF-отчёт»
- Декор: два полупрозрачных круга (не полосы)

### 2. Проблема (светлый)
- Кикер `ЗАЧЕМ ЭТО НУЖНО`; H1 «Перед поступлением и первой работой негде ошибиться»
- 3 проблемные карточки с номерами 1–3: «Один шанс на ответ», «Советы противоречат друг другу», «Простой вопрос неловко задать»
- Внизу сравнение: серая карточка «СЕЙЧАС» («Одна попытка, ноль обратной связи — ошибка закрепляется») → teal-стрелка → teal-tint карточка «С «ПРОЖАРКОЙ»» с 3 галочками (оценка 0–10, честный разбор, пример ответа)
- Подпись снизу курсивом: «Ошибка в тренажёре не стоит ничего — в жизни стоит поступления или стажировки»

### 3. Один чат закрывает весь путь (скрин №1 = меню с «👑 Лидерство»)
- Слева 3 ряда-режима с бейджами (? / ✓ / ↑): Инфо-режим, Экзаменатор, Прогресс и отчёт
- Справа скрин меню (квадрат), в белой рамке с тенью
- Внизу полоса «СЦЕНАРИИ»: 4 чипа — 🎓 Выбор вуза, 💼 Поиск работы, 🤝 Адаптация в компании, 👑 Лидерство · этап 4
- Геометрия: скрин h=4.4 (низ на 5.9), полоса y=6.2 — не пересекается

### 4. Инфо-режим (скрин №2 = чистый ответ с «📚 Источники»)
- H1 «Ответ по базе знаний, а не из головы модели» — одна строка, ширина ограничена левой колонкой
- Справа вертикальный скрин (ar≈0.63, h=5.55, y=1.5)
- Слева 4 ряда с ✓-бейджами: «Блок 📚 Источники под каждым ответом», «Поиск TF-IDF со стеммингом», «Поиск ограничен сценарием», «Ключевые факты, приятная подача»
- Ряды: старт 1.9, шаг 1.28, описание ≤2 строк

### 5. Экзаменатор (скрин №3 = нормальный тест с кнопками A–D)
- H1 «Каждое второе задание — тест с кнопками»
- Ряды: «Тесты A–D и открытые вопросы», «Сломанный тест не тормозит сессию» (бот чинит), «Отвечать можно текстом и голосом», «Индикатор загрузки»

### 6. Разбор (скрин №4 = разбор открытого вопроса: балл, верно/улучшить, пример, источники)
- H1 «Каждый ответ разбирается по одной честной схеме»
- Скрин СЛЕВА (смена стороны для ритма), 4 ряда справа: «Единая схема разбора», «Выбранный и верный варианты помечены ✅/❌», «Переписка остаётся чистой», «Бросить на нулях нельзя»

### 7. Бот помнит слабые темы (скрин №5 = финал с рекомендациями и уточняющим вопросом)
- Выравнивает пустоту старого слайда 7: слева 4 вертикальных шага (1 Записывает → 2 Помечает слабую → 3 Возвращается → 4 Добивает), справа скрин
- Кикер `АДАПТИВНОСТЬ · ЭТАП 3`
- Подпись-пример курсивом под контентом

### 8. Результат остаётся с тобой: PDF, голос и два языка
- 2×2 карточки: «PDF-отчёт», «Кнопка или /export», «Голосовые всегда», «RU/EN и inline-поиск»
- Подпись для комиссара: «достаточно пройти 5 шагов: /start → сценарий → вопрос → 3 задания → PDF»

### 9. Инженерное качество проверено 406 автотестами
- Кикер `ПОД КАПОТОМ`
- Чип-флоу: Telegram → aiogram 3 → поиск TF-IDF → GigaChat-2 → SQLite и PDF
- 3 больших стата (52pt teal): 76 файлов базы (состав), 70 из 76 с источником, 406 автотестов
- Полоса стека: Python 3.12 · aiogram 3 · GigaChat (Сбер) · SQLite v5 · SpeechRecognition + edge-tts · fpdf2 · реестр промптов · ruff + CI

### 10. ЭТИКА И БЕЗОПАСНОСТЬ (новый)
- Кикер `БЕЗОПАСНОСТЬ`; H1 «Бот безопасен для школьника»
- 3 карточки с бейджами:
  1. «Не собирает личные данные» — не просит телефон, адрес, ФИО; прямо просит их не присылать
  2. «Защита от prompt-injection» — ввод очищается, «ignore previous instructions» и русские аналоги вырезаются, лимит 2000 символов
  3. «Честный дисклеймер» — в каждом разборе и в PDF: рекомендации информационного характера
- Полоса снизу: «Данные берутся только из открытых источников, источник указывается рядом с фактами»

### 11. Итог (тёмный)
- Кикер `ЧЕСТНО О ПРОБЛЕМАХ И РЕШЕНИЯХ`; H1 «Проблемы демо-хостинга уже решены»
- 3 карточки ПРОБЛЕМА→РЕШЕНИЕ (UptimeRobot, SSL-конфиг GigaChat, валидация и дисклеймер)
- Tint-полоса-итог: «Итог: отвечает с источниками, разбирает ошибки и помнит слабые темы»
- 3 футер-ссылки: репо · демо · «полностью рабочий демонстрационный режим»
