## 2. Критические проблемы (требуют немедленного решения)

### 2.1 Render Environment Variables (Критично)
**Проблема:** На Render в Environment Variables должны быть заданы:
- `GIGACHAT_VERIFY_SSL_CERTS` = `false` (уже в `render.yaml`, но проверить дашборд)
- `GIGACHAT_MODEL` = `GigaChat-2` (в `render.yaml`, но может отсутствовать в дашборде)
- `BOT_TOKEN`, `GIGACHAT_CREDENTIALS`, `ADMIN_IDS` — уже есть (по скрину)

**Действие:** Проверить Render Dashboard → Environment Variables → убедиться, что все 6 переменных присутствуют и совпадают с `render.yaml`.

### 2.2 DB миграция на Render (Критично)
**Проблема:** Таблица `dialog_history` создаётся при `init_db()` (миграция v3→v4). На Render БД эфемерна — при редеплое пересоздаётся.
**Действие:** После деплоя Render должен автоматически применить миграцию v3→v4. Проверить логи Render на наличие `Миграция v3→v4: добавлена таблица dialog_history`.

### 2.3 База данных эфемерна (Архитектурно)
**Проблема:** `render.yaml:31-33` — free tier Render не имеет persistent disks. БД и `learning_errors.json` теряются при каждом редеплое/рестарте.
**Варианты решения:**
1. **Быстрый:** Перейти на Render Pro ($7/мес) с Persistent Disk
2. **Правильный:** Использовать внешнюю БД (PostgreSQL на Render / Supabase / Neon) — требует переписать `db.py` под asyncpg
3. **Минимальный:** Оставить как есть — для демо/конкурса допустимо (как указано в комментарии `render.yaml:33`)

**Рекомендация:** Для SK Kids Challenge (демо) оставить вариант 3. Документировать в README ограничение.

## 5. Тесты и качество (Средний приоритет)

### 5.1 Ошибки окружения (13 штук)
**Проблема:** `PermissionError: [WinError 5] C:\Temp\...\pytest-of-...`
**Причина:** pytest `tmp_path` фикстура не имеет прав на запись в `C:\Temp` в этом окружении.
**Решение:**
1. Настроить `pytest.ini` с `tmp_path_factory` или `--basetemp` в другую директорию
2. ИЛИ игнорировать эти ошибки как окружение (они не связаны с кодом)
3. В CI/CD (GitHub Actions) ошибок нет — проверить `.github/workflows/`

### 5.2 Добавить тесты для новой памяти
